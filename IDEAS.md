# Puzzle ideas

Every puzzle considered for the site, one row each with variants grouped: ideas from earlier chats and the owner's idea list, games the owner plays, the GoComics puzzles, Simon Tatham's collection and the puzzles on wordleunlimited.io. Games already on the site are rows too, marked Built, so overlaps stay visible.

Rows are sorted by group, then status: Yes, Look closer, Option, Idea, Built, No. When a game ships, set its row to Built (or add a row) in the same PR.

- **Clues?** None; Definitions (dictionary definitions would do); Written (needs clues or categories someone writes, which rules it out).
- **Status** only sorts the rows; it doesn't mean approved. Nothing here is approved or requested until the owner asks for that game, and an idea named in several chats or lists is not a request because of that.
- **Ease** of adding it, with the `new-game` skill and what's already on the site (the shared word lists and Wiktionary meanings, the toy library and cats, Catlas's map, and the solvers and generators of the games built): Easy = a simple generator, or mostly reuses a built game or shared file; Medium = a new generator plus a solver to guarantee one answer; Hard = needs new art, physics, split-second timing, a big data file, or a generator that's slow to make puzzles with one answer.
