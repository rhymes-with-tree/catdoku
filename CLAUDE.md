# Catdoku

A site of cat-themed puzzle games; `README.md` describes every game and what they share.

- **To do:** open items put aside for later are in `TODO.md`. Check it when starting work, add to it when something is
  put aside, and take an item out in the same PR that finishes it.
- **Ideas:** every game considered, with its status and cat theme, is in `IDEAS.md`.
- **Apple's guidelines:** the review and its own "Still to do" list are in `HIG.md`.
- **Pictures:** who's who among the cats, and which game uses which picture, is in `ARTWORK.md`.
- **New games:** use the new-game skill (`.claude/skills/new-game/SKILL.md`).
